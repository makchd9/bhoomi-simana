# Native-media delivery audit

## Actual causes

- The opening `three-towers-side.webp` is an earlier generated illustrative composite at **1672×941**, not an HD image provided by the owner. A 1440px-wide, 2× display needs about 2880 physical pixels before additional zoom. Increasing the Next image quality cannot supply the absent detail. The previous request's scale and perspective transforms added another resampling pass.
- Main video exports previously decoded through AVFoundation RGB, JPEG 98 intermediates and another colour conversion before a fixed-bitrate H.264 encode. Source and old output differ in detail and colour; resolution metadata alone was not a fidelity check.
- The small mobile video was selected purely by CSS viewport width, which also shrinks during browser zoom. High-density/zoomed small viewports could receive the smaller version.
- Owner photo preparation reduced 3840–7680px originals to 2560px / lossy WebP 88. These files belong to the retained image library; they are not the moving clubhouse footage in the current tour.
- Journey posters and the opening image underwent another Next image compression pass. The original clubhouse film itself is only compressed 1080p.

## Changes

- New versioned **native-v3** clips encoded directly from original video, with no JPEG/RGB intermediate. Native 3840×2160 tower; 1920×1080 clubhouse. H.264 CRF 16, six-frame GOP, no B-frames and faststart balance detail with reversible seeking. Existing frame-paced seek controller is retained. Dedicated 1080×1920 files remain only for small displays whose physical viewport is at most 1080px wide.
- Lossless, native-size WebP posters, served without Next recompression or downscaling. Far-away posters are deferred until needed; already loaded posters remain available through scene transitions.
- Clubhouse brochure exterior re-extracted at **3397×2700**, preserving the existing view; the brochure image source determines the useful resolution.
- All eleven retained owner renders restored to their original pixel dimensions with lossless WebP. Decoded-pixel comparisons are recorded in `native-photo-audit.json`. Versioned paths avoid the old resized-image cache; source dimensions in project data now match files. Responsive image candidates support the available 5K/8K originals elsewhere in the image library.
- Hero motion is a small translation aligned to device pixels. Removed continuous enlargement and 3D texture resampling; no invented sharpening, AI detail or resolution claims.

## Source limitations

The exact three-tower opening composition has **no supplied high-resolution equivalent**. It remains a 1672px illustrative image. Its architecture cannot be made truly sharp under arbitrary enlargement without an original high-resolution render of that arrangement. Generating/upscaling would invent detail. The public clubhouse video also cannot recover detail lost in its original compression. Those limitations are not fixed by relabelling media as 4K.

## Reproduction

Run `scripts/prepare-native-media.mjs` with paths to FFmpeg (libx264), the owner's Bhoomi master, and the official clubhouse film. Native photos are generated by `scripts/prepare-owner-photos.mjs`. No runtime access to the owner's Downloads folder is required.

`native-video-audit.json` compares the same first tower frame from the source, previous export and replacement, using one decoder. The PSNR measurement covers both colour and pixel differences for this sample; it is not a guarantee of perceived quality for every frame or unlimited zoom.

## Verification completed

- Production build, lint and TypeScript passed.
- 24 existing browser checks passed; both new 2× pixel-density checks passed after correcting their URL assertion to accept the browser's absolute source URL (26 cases total).
- Desktop and 720px high-density/zoom-sized viewports receive 3840px tower video and 3840px original posters, with no Next recompression request for these assets.
- All eleven full-size owner WebP renders decode to exactly the original RGB pixel values.
- Same-decoder tower sample PSNR improved from 28.44 dB to 46.69 dB. This includes colour-path correction and compression differences; it is a sample fidelity measurement, not a universal sharpness claim.
- All fourteen video outputs have their expected frame counts. The six-frame GOP still passes the two-frame-step forward/reverse seek and settling test.
