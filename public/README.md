# Project assets

- images/: approved architecture, interiors, lifestyle and amenity photography (prefer WebP/AVIF).
- videos/: optional compressed muted hero/background video, with matching image poster.
- models/: supplied GLB/GLTF and any supporting textures. Prefer self-contained compressed GLB.
- floorplans/: approved floor and apartment plans. Never infer dimensions from imagery.
- icons/: project-specific vector assets only; UI icons use Lucide.
- fonts/: licensed, locally hosted WOFF2 font files and their licence notices.

Register paths and accurate alt text in src/data/assets.ts or the relevant content record. Supply image intrinsic dimensions. Nothing in this directory currently represents a real development.
